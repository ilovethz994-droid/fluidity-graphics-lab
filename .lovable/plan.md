# Lumbyte OS 前端设计系统与集成方案

## 目标
保持官方 `founderwavechasecn/lumbyte-os` 的 Next.js 产品核心、现有接口、Neon Auth 与全部真实业务能力不变，仅重塑信息架构与视觉驾驶舱。仅使用已上传的官方 Logo；第二张图片仅作为液态玻璃层次、桌面密度和布局节奏参考，不复制其 Logo、金融业务或具体界面。

## 仓库现实与执行边界
- 已核实当前 Lovable 工作区是独立的 TanStack Start 空白项目，不是官方 `founderwavechasecn/lumbyte-os` Next.js 仓库。
- 当前工作区也没有可访问的官方 Lumbyte 项目副本，因此不能在这里声称完成真实后端、Neon Auth 或业务接口集成。
- 在官方仓库接入前，本工作区只用于产出可迁移的视觉规范、组件接口和隔离的设计预览；不创建平行产品，不迁移框架，不重建后端，不创建假 API、假认证或假成功流程。
- 最终生产实施必须在官方 Next.js 仓库内进行，直接复用现有路由、组件、数据契约、鉴权与服务器状态。

## 实施范围

### 1. 品牌与设计系统
- 上传并接入官方 Logo，在导航、登录、工作区和 favicon 中原样使用。
- 建立暖白、冰蓝、淡紫环境光背景与高可读液态玻璃组件体系。
- 统一中文字体层级、边框、阴影、状态色、间距、动效和可访问焦点样式。
- 遵守数据真实性：缺失值显示“尚未验证”或“暂无可靠公开证据”，绝不以 0 或虚构数字填充。

### 2. 公开网站与身份入口
- 首页包含产品主张、真实数据原则、证据体系、工作流程、核心模块、决策与财务方法、数据新鲜度、信任理念及最终行动入口。
- 提供产品、工作方式、真实数据、证据体系、决策系统、方案、关于、条款、隐私、AI 与数据声明页面。
- 重塑官方仓库现有登录与注册页面，并完整保留 Neon Auth 的真实登录、注册、会话与恢复流程。
- 不增加后端尚未支持的手机号验证码、邮箱验证码或微信扫码登录，也不制作任何假登录成功状态。

### 3. 产品工作区
- 构建桌面优先的统一外壳：顶部栏、项目上下文、侧边导航、配额与数据核验状态。
- 提供项目列表、创建项目、工作台、行业、客户、竞品、定价、商业模式、财务、风险、证据、决策、最终报告及设置页面。
- 核心页面采用与业务匹配的表格、证据抽屉、假设编辑、情景切换、报告阅读和确认弹窗，不做金融看板复刻。
- 生产工作区只渲染现有 API 的真实项目数据，以及真实的加载、空、错误、“尚未验证”或“暂无可靠公开证据”状态。
- 若当前独立工作区需要设计预览，预览数据必须与生产路径完全隔离并明确标注，不得进入真实用户项目。

### 4. 交互与适配
- 完成导航、筛选、搜索、抽屉、弹窗、标签切换、项目创建、假设编辑与报告导出反馈等前端交互。
- 重点适配 1440–1920px 桌面；1024–1280px 收起侧栏；移动端提供可用降级布局。
- 所有页面设置独立标题与描述，保留单一 H1、语义结构和图片替代文字。

## 技术说明
- 生产目标保持官方 Next.js、TypeScript、Tailwind、Hosted Neon PostgreSQL 与 Neon Auth 技术栈，不做 TanStack Start 迁移。
- 设计颜色与视觉效果全部进入全局语义变量，页面不硬编码颜色。
- 将现有 Lumbyte 产品核心视为冻结：项目、研究、证据、财务、风险、决策、报告、新鲜度、配额、用量、多用户隔离与所有计算语义均不重写。
- 保持 `UNKNOWN != ZERO`、`DATA_GAP != NEGATIVE`、`FACT != ESTIMATE/SIGNAL/INFERENCE`、`USER_PROVIDED != VERIFIED FACT`、`CUSTOM_PRICING != NUMERIC PRICE`、`STALE != CURRENT`。
- 组件以 Next.js 可迁移的 React/TypeScript 接口设计；真实接入时适配现有数据契约，不以本地状态代替服务器状态。

## 正确实施顺序
1. 获得并审计官方 Next.js 仓库的现有路由、组件、数据契约、鉴权与状态处理。
2. 锁定官方 Logo，建立可迁移的设计令牌与液态玻璃基础组件。
3. 先改登录/注册外观但保留真实 Neon Auth，再改应用外壳。
4. 按决策、工作台、财务、证据、报告及其余模块顺序逐页替换界面，不改业务逻辑。
5. 重塑公开网站，并只使用真实、经过选择的产品预览。
6. 对项目、研究、重试、重新分析、假设、场景、导出、新鲜度、配额与多用户隔离做完整回归验证。

## 验证
- 检查构建、运行时错误与浏览器控制台。
- 在桌面和窄屏视口逐页检查布局、文字溢出、对比度、导航和关键交互。
- 核对官方 Logo 使用、无金融品牌残留、无虚构数字、无工程术语泄露。
- 在官方仓库内验证所有原有功能与 Neon Auth 行为均未被视觉重塑破坏；在此之前不宣称集成完成。
